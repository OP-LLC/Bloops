# Bloops roadmap

## Done

**v0.1: first blob**
- Transparent, always-on-top, click-through window; one blob per Claude Code chat
- Hooks to localhost, fail silently when Bloops is closed
- Idle bounce, chill, sleep after 30 min, poof after 60 min, wake on activity
- Auto color per chat, hue wheel, drag anywhere, speed slider

**v0.2: animation set**
- Reading, typing, gear (Bash), rage (PowerShell), browsing, thinking, delegating
- Needs you, done, failed, long-task sweat, snooze bubble
- Spawn drop, goodbye wave + poof, pet, carried/dropped
- Idle extras: yawn, juggle, look around, high-fives between neighbors

**v0.3: polish**
- Colors saved per chat, preset swatches
- Sits on the taskbar, desktop icon and logo

**v0.4: animation pack v2**
- Squish on /compact, package toss on git push, rocket on deploy
- Pout when a permission is denied, bucket while downloading, headphones for audio work
- Agent squad orbit (3+ subagents), rare idles
- Hats saved per chat, holiday hats

**v0.5: hats + menu**
- Menu tabs: Color, Hats, Settings
- Halo, goggles beanie, rubber duck; all hats tuned to sit on the head
- Animation props draw in front of hats
- Fix: Dismiss Bloop no longer closes every Bloop

**v1.0: release**
- Self-contained exe (no .NET install needed)
- Connect to Claude on first launch, Connect/Disconnect button, Start with Windows, version in Settings
- "Done" flag wave and "needs you" bubble
- 17 new hats: rain cloud, moon, sprout, orca, shark fin, choir note, dino hood, Raspberry Pi, hard hat, grad cap, chef hat, traffic cone, mushroom, frog, captain hat, donut, OP sticker
- Sounds (done ding by default; all sounds, volume, mute in Settings)
- Freeze watchdog + "Open log folder" for bug reports
- Fix: head outline no longer draws a line through hats
- Source-available license

## Ideas for later

- Purple studio headphones, hard hat auto-on during long Bash runs
- Size setting (small / normal / big)

- Lots more unique hats (some current ones may rotate out)
- Multi-monitor: remember where each Bloop was dropped
- Unlockable hats (streaks, long sessions)
- macOS/Linux version
